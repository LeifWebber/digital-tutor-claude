# AI 教师数字人方案调研

为 maic-avatar 的 AI 教师选数字人方案：对比各家在**预渲染**和**实时交互**两种方式下的效果、速度、价格，以及用真人照片创建教师分身的难易程度。阿里云（通义万相、百炼）为重点；HeyGen 因预渲染价格过高，不在推荐范围内。

## 结论

| | 讲课（预渲染） | 答疑（实时） | 一节课讲课视频成本 | 结论 |
|---|---|---|---|---|
| **组合 A** | anam 离线视频 | anam 实时 | $3–4.3（约 20–29 元），一次性 | ✅ **主推**：同一个老师形象，改动最小，最便宜 |
| **组合 B** | 阿里万相数字人视频创作 | anam 实时 | 约 162 元（只出镜 25% 约 40 元） | ⚠️ 备选：透明背景可叠在幻灯片上，但不够自然 |
| 淘汰 | 百炼 wan2.7-i2v | 万相 2D 实时、Simli、HeyGen LiveAvatar | — | ❌ 实测不达标 |

完整推荐见 [推荐方案.md](推荐方案.md)，网页版见 `site/index.html`。

## 口径

- 汇率：1 美元 = 6.69 元，取自 2026-11-05 的 open.er-api.com。完整报告正文按 7.1 计算，人民币数字偏高约 6%；顶部更新一节已改按 6.69。
- 价格分三类标注：官方（厂商定价页或文档）、第三方（聚合站或评测文章）、推算（按官方单价和项目用量计算）。anam 离线视频的单价来自 anam 的邮件回复。
- 打分为 1–5 分，依次是"口型 / 自然度 / 能否上课"，由测试者主观打分。印尼语口型还没有母语者打分。
