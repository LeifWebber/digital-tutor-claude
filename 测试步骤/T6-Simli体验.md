# T6 Simli 试玩

P1 · 20 分钟 · 0 元（免费 50 分钟）

**为什么做**：Simli 只负责渲染头像，声音用我们自己的。价格约 $0.01/分钟，是 anam 的十分之一。答疑这部分如果以后用量很大，它是最可能的省钱替代。这次只看画质和速度能不能接受，值得以后投开发，就记为组合 C；不能接受，就把组合 C 划掉。

## 步骤

1. 打开 https://app.simli.com 注册，免费额度只能用模板形象。
2. 在控制台的 demo 里选一个形象开始对话，用 T3 的 3 个问题提问，用秒表记录回答延迟和首帧时间。
3. 重点看三件事：待机时有没有僵硬或抖动、说话时口型准不准、画面清晰度够不够投到大屏上。
4. 不用照片做分身。Simli 用照片生成分身要付费套餐，还要等约 4 小时，等组合 C 真要落地时再做。

## 记录

在 `测试记录.csv` 的 T6 行填首帧时间、回答延迟和 3 项打分。

## 判定

"能上课"≥4 分，且回答延迟与 anam 差距在 0.5 秒以内，组合 C 就留着，作为以后降成本的方案。
