**刻意没测的**，以及原因：
- **TTS 横评**：语音每分钟只要几分钱；ElevenLabs 的印尼语音色项目里已经在用。
- **腾讯、百度、火山**：都要先买形象和时长包，单家起步 1,000–2,600 元，超出 MVP 预算。
- **其他海外实时厂商**：价格和接入方式都不如 anam 或 Simli。
- **OmniHuman 1.5**：画质口碑好，但每分钟 $4–10，是 anam 离线视频的 30–90 倍，只适合少量精品片段。
- **精细测延迟**：手机秒表测 3 次取中间值，已经足够判断。

## 打分标准（1–5 分）

- **口型**：5 = 看不出不同步；3 = 偶尔对不上；1 = 明显错位
- **自然度**：5 = 像真人录像；3 = 看得出是 AI，但不出戏；1 = 表情怪异，或嘴部、牙齿有伪影
- **能否上课**：5 = 可以直接给学生看；3 = 勉强能用；1 = 不能用
