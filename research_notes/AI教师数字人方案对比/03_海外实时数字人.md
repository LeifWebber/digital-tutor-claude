> 研究时间：2026-11-04。所有价格均来自研究当日抓取的官方定价页，除非另注日期或标注“第三方/未验证”。未登录任何控制台。

## 问题 1：价格（每分钟单价、免费额度、月最低消费、并发限制、自定义形象费用）

### Takeaway
anam 的实际单价约 $0.11–0.12/分钟（Professional 套餐，10k–50k 分钟/月），企业价“低至 $0.04”。**只做渲染的 audio-to-video 厂商便宜很多**：Simli 约 $0.009，bitHuman 云端约 $0.04，Beyond Presence Speech-to-Video 约 €0.0875，Synthesia Interactive（自带语音和 LLM）为 $0.10。Tavus 约 $0.25 以上，属于最贵的一档。**一个重要变化：HeyGen LiveAvatar 现在的 LITE 模式只要约 $0.08–0.09/分钟，FULL 模式约 $0.16–0.18**，已经不比 anam 贵了。团队当初否掉 HeyGen 的价格依据可能已经过时，建议重新核算。

## 问题 2：延迟（首帧 / 端到端响应）——厂商宣称与独立测量

### Takeaway
目前**没有真正中立的第三方基准**。可用的都是厂商自测：anam（2026-10-16）测得自家回复中位数 1.24s、连接 1.42s，均领先 Tavus、HeyGen、LemonSlice。但在共享 LiveKit 管线的对照里，anam 和 Synthesia 没有显著差异。LemonSlice 自测（2026-04）则称自己比 Tavus Phoenix-4 和 anam Cara-3 快，与 Simli、LiveAvatar 相当。

### Cited Findings
- anam 自测（2026-10-16，60 人，960 场对话，各家用默认全管线）：
  - 回复延迟 p50/p95：anam 1.24/1.84s，HeyGen 1.82/2.52s，Tavus（phoenix-4.5）1.86/3.62s，LemonSlice 2.10/3.06s。
  - 连接首帧（TTFF）p50：anam 1.42s，HeyGen 3.66s，Tavus 5.00s，LemonSlice 9.72s。
  - — [anam latency benchmark](https://anam.ai/tools/latency-benchmark)
- 同一研究的 LiveKit 共享管线对照（1,200 场对话，只换 avatar）：
  - 回复 p50：anam 2.12s，Synthesia 2.20s，Tavus 2.46s，HeyGen 2.58s，LemonSlice 2.70s。
  - TTFF p50：anam 2.76s，Synthesia 3.44s。
  - anam 自己承认，配对比较“未能证明”相对 Synthesia 有速度优势；也承认存在利益冲突。
  - — [anam latency benchmark](https://anam.ai/tools/latency-benchmark)
- LemonSlice 自测（2026-04-15，LiveKit 环境，Deepgram + Qwen3-32B@Groq + Cartesia，N=50）：自家 TTFB 471ms，端到端平均 2.04s；显著快于 Tavus Phoenix-4 和 anam Cara-3，与 LiveAvatar、Simli 无显著差异。— [LemonSlice Flash blog](https://lemonslice.com/blog/lemonslice-flash)
- 厂商宣称（各家测量口径不同，不可直接比较）：
  - anam：服务端生成约 150–180ms，对话低于 1s
  - Tavus：低于 600ms
  - Simli：低于 300ms
  - Beyond Presence：推理低于 100ms，全球 ≤250ms
  - D-ID V4：对话轮次低于 0.5s（第三方测试评价偏慢）
  - — [meet-cody 2026-08](https://meet-cody-website-xr0tt.kinsta.page/blog/real-time-ai-avatar-models-compared/)；[bey docs](https://docs.bey.dev/integrations/speech-to-video.md)；[D-ID V4 新闻稿 2026-03](https://elearningindustry.com/press-releases/d-id-launches-v4-expressive-visual-agents-for-real-time-ai-interaction)
- anam + ElevenLabs Agents 集成的官方延迟预算：STT 200–400ms + LLM 300–800ms + TTS 到 avatar 100–200ms，合计约 600–1400ms；比 anam 一体化方案多出一些延迟。— [anam ElevenLabs integration](https://docs.anam.ai/third-party-integrations/elevenlabs)
- Tavus 文档承认：用自定义 LLM “很可能增加延迟”；Echo 模式下由服务器转发视频也会增加延迟。— [Tavus modes](https://docs.tavus.io/sections/conversational-video-interface/modes-and-layers)
- 一项 178 人的盲测发现，“响应速度”与整体体验的 Spearman 相关系数为 0.697，高于画质的相关性。— [meet-cody 2026-08](https://meet-cody-website-xr0tt.kinsta.page/blog/real-time-ai-avatar-models-compared/)

### Inferences
- 对 AI 教师来说，端到端延迟主要由 STT、LLM、TTS 决定（2s 左右），avatar 本身在共享管线下只差约 0.1–0.5s。**连接首帧（TTFF）差异反而更大**（1.4s 对 5–10s），会直接影响“打开一页课件就开讲”的体验，必须实测。

### Gaps
- Simli、Beyond Presence、bitHuman、Keyframe 没有被纳入任何可读到数值的第三方测量。
- 没有任何从印尼或中国发起的延迟测量。

## 问题 3：质量（真实感、唇形同步、待机动作、伪影、口碑）

### Takeaway
口碑大致分三档：
- 第一档：anam、Tavus、LiveAvatar（真实感强）。
- 第二档：Beyond Presence（画质和带宽自适应好，但上限“像吉祥物”）、LemonSlice（唯一有手势和全身）。
- 第三档：Simli（最便宜，待机动作弱）、bitHuman（“可接受”）。

D-ID V4 宣称支持 4K 和更强表现力，但缺少独立评测。

### Cited Findings
- 2026-08 第三方汇总的各家口碑：
  - anam：178 人盲测排第一，微表情好；但会话加入慢，低带宽表现差。
  - Tavus：垂直整合最深，但超额费最高；有买家反馈自定义形象做到约 66% 时报错。
  - LiveAvatar：待机行为最好，情绪幅度偏平。
  - Simli：待机状态弱。
  - Beyond Presence：画质和带宽适配属第一梯队，但上限“像吉祥物”。
  - LemonSlice：手势最强。
  - bitHuman：画质可接受。
  - D-ID：无 SDK，测试中偏慢。
  - — [meet-cody 2026-08-28](https://meet-cody-website-xr0tt.kinsta.page/blog/real-time-ai-avatar-models-compared/)
- LemonSlice 自家对比表：只有它和 LiveAvatar 支持手势；只有 LemonSlice 支持全身和动物形象；LemonSlice 和 anam 支持“单图即时生成”。— [LemonSlice Flash](https://lemonslice.com/blog/lemonslice-flash)
- Tavus Phoenix-4 是唯一支持全身取景的 Tavus 模型，要求人脸至少占画面 25%。— [Tavus Phoenix-4 requirements](https://docs.tavus.io/sections/faces/phoenix-4-video-requirements)
- D-ID V4 Expressive（2026-03-16 发布）：基于扩散模型，用真人演员表演数据训练，唇形同步最高 4K。— [eLearning Industry 2026-03-17](https://elearningindustry.com/press-releases/d-id-launches-v4-expressive-visual-agents-for-real-time-ai-interaction)

### Inferences
- 我们的场景是课件旁的小窗老师，不是全屏。Simli 和 bitHuman 的画质短板在小窗下可能可以接受，但必须由人工盲测确认，尤其是待机（学生思考时）和打断时的表现。

### Gaps
- 没有找到系统性的第三方画质基准（例如 FID 或唇形同步指标），口碑主要来自一篇 2026-08 的汇总文和厂商自测。

## 问题 4：架构适配（浏览器 WebRTC SDK、自带 LLM/TTS、推原始音频、打断、透明背景、Token 签发方式）

### Takeaway
所有主流厂商都能“自带 TTS / 推音频驱动口型”。差别主要在：有没有**纯浏览器 JS SDK**（anam、Simli、D-ID、LiveAvatar 有），还是**以 LiveKit/Pipecat 服务端插件为主**（Beyond Presence、Synthesia、Keyframe、bitHuman、Runway、TruGen 等）。如果改走 LiveKit 路线，就要多维护一个 LiveKit Agents 服务端，但从此可以随时切换 avatar 厂商。

### Cited Findings
- LiveKit Agents 支持 16 家 avatar 插件：Anam、Avatario、AvatarTalk、Beyond Presence、bitHuman、D-ID、Keyframe、LemonSlice、LiveAvatar、Protoface、Runway、Simli、Spatius、Synthesia、Tavus、TruGen。其中 Anam、bey、D-ID、LemonSlice、Protoface、Runway、Tavus、TruGen 同时有 Node.js 版。— [LiveKit avatar models](https://docs.livekit.io/agents/models/avatar/)
- Pipecat 支持的视频服务：Anam（社区）、bitHuman（社区）、HeyGen、Protoface（社区）、Simli、Tavus。— [Pipecat supported services](https://docs.pipecat.ai/server/services/supported-services)
- anam 文档显示的能力：
  - 支持自定义 TTS 和 audio passthrough（Python cookbook 标注为 beta，API 可能变动）。
  - 支持 ElevenLabs 服务端集成，音频要求 PCM16 / 16kHz / 单声道；另一份 cookbook 建议 24kHz，两处说法冲突。
  - 服务端自定义 LLM 配置曾标注“即将推出 / 需联系支持开通”。
  - — [anam custom TTS](https://docs.anam.ai/examples/custom-tts)；[anam ElevenLabs](https://docs.anam.ai/third-party-integrations/elevenlabs)；[anam audio passthrough cookbook 2026-02-19](https://anam.ai/cookbook/python-audio-passthrough-tts)；[anam custom LLMs](https://anam.ai/docs/personas/llms/custom-llms.md)
- Simli：
  - SDK 输入音频、输出唇形同步视频。
  - 提供浏览器 JS SDK；后端签发 session token，避免 API key 暴露在前端。
  - 也支持 Python SDK、原生 WebRTC、LiveKit 和 Pipecat。
  - 音频需为 16kHz PCM 分块。
  - Trinity-2 文档包含背景/前景和镜头设置。
  - — [Simli docs](https://docs.simli.com/)；[Simli SDKs](https://docs.simli.com/simli-sdks)；[Simli dev.to](https://dev.to/simli_ai/how-to-create-real-time-ai-video-avatar-in-7-minutes-2i29)；[Pipecat Simli](https://docs.pipecat.ai/api-reference/server/services/video/simli)
- Beyond Presence Speech-to-Video：
  - 你的管线负责 transport、轮次检测、STT、LLM、TTS；bey 负责从音频生成视频，宣称约 250ms。
  - 官方建议优先用 LiveKit 插件，不建议直接调用 `POST /v1/sessions`。
  - — [bey speech-to-video](https://docs.bey.dev/integrations/speech-to-video.md)；[bey create session](https://docs.bey.dev/api-reference/speech-to-video-sessions/create-speech-to-video-session.md)
- Tavus 的四种模式：
  - 全管线：官方推荐，延迟最低。
  - Custom LLM：可接 OpenAI 兼容端点。
  - Text Echo / Audio Echo：绕过 Tavus 的 STT 和 LLM，直接让 replica 说你给的文本或音频。
  - Echo 模式与感知层、STT 层不兼容。Tavus 的传输基于 Daily WebRTC 房间。
  - — [Tavus modes and layers](https://docs.tavus.io/sections/conversational-video-interface/modes-and-layers)
- LiveAvatar LITE（Custom）模式：只提供 avatar，自带 LLM/TTS，价格为 FULL 的一半；ElevenLabs Agents 有官方 LiveAvatar 集成指南。— [LiveAvatar LITE overview](https://docs.liveavatar.com/docs/lite-mode/overview)；[ElevenLabs × LiveAvatar](https://elevenlabs.io/docs/it/eleven-agents/guides/integrations/live-avatar.md)
- Synthesia avatar-only 档：自带语音和 LLM，avatar 以视频参与者身份加入你的 LiveKit 房间；插件目前只支持 Python LiveKit Agents。— [Synthesia Interactive Avatar API](https://www.synthesia.io/post/interactive-avatar-api-real-time-avatars)；[LiveKit Synthesia](https://docs.livekit.io/agents/models/avatar/plugins/synthesia)
- D-ID V4 Agents：通过 WebRTC 实时流式传输，D-ID Client SDK 负责 WebRTC 和聊天 UI；支持接入 LLM。— [D-ID V4 新闻稿](https://trainingindustry.com/press-release/artificial-intelligence/d-id-launches-v4-expressive-visual-agents-for-real-time-llm-connected-interaction-at-enterprise-scale/)
- bitHuman 是唯一主流的本地/自托管方案（$0.02/分钟，自托管会话数不限）。— [bitHuman pricing](https://www.bithuman.ai/pricing)；[meet-cody](https://meet-cody-website-xr0tt.kinsta.page/blog/real-time-ai-avatar-models-compared/)

### Inferences
- **最接近“直接替换 anam”的是 Simli**：同样是浏览器 JS SDK、后端签发 token、推 ElevenLabs 音频。LiveAvatar LITE 也可以直接替换。其他厂商大多需要引入 LiveKit 或 Daily 服务端。
- 如果团队愿意改用 LiveKit Agents（服务端跑 STT→LLM→ElevenLabs TTS→avatar 插件），就能用同一套代码 A/B 测试 anam、Simli、bey、Synthesia、LemonSlice、Keyframe、Tavus、LiveAvatar，切换成本最低，也最适合人工对比测试。

### Gaps
- 打断（barge-in）在 audio-to-video 模式下通常由我方管线负责（停止推音频或 flush），各家“清空缓冲”接口的细节未逐一核实。
- 透明背景 / 绿幕：只确认 Simli Trinity-2 有背景设置；其他厂商未核实。

## 问题 5：自定义形象创建（单张照片 vs 2 分钟视频、处理时间、授权要求）

### Takeaway
单张照片即可生成的有：anam（one-shot）、LemonSlice、Runway Characters、Simli（上传图片）、bitHuman Essence 2（几分钟完成）。需要视频训练的是 Tavus：Phoenix-4 需要约 30 秒说话 + 30 秒倾听，外加本人朗读授权声明，训练耗时 3–5 小时。

### Cited Findings
- anam one-shot：可用单张照片（真人、图库或 AI 图）生成；PNG/JPG/WebP，≤4.5MB，方形且 ≥1152×1152，人脸清晰、手不入镜；会经过审核和面部兼容性检查；文档中只出现 Cara 4 系模型（cara-4、cara-4.1-express），处理时长未说明。— [anam custom avatars](https://anam.ai/docs/personas/avatars/custom-avatars)
- Tavus replica：
  - 旧规范：一段至少 2 分钟的连续视频（授权声明 + 1 分钟说话 + 1 分钟静默）。
  - Phoenix-4 新规范：30 秒说话 + 30 秒倾听。
  - 只有“个人 replica”需要授权声明，且必须由本人说出，任何受支持语言均可。
  - 训练耗时 3–5 小时（不同页面说法不一）。
  - 文档有冲突：有的页面说新 replica 默认用 phoenix-4，有的页面说自定义仍是 Phoenix-3。
  - — [Tavus replica training](https://docs.tavus.io/sections/replica/replica-training)；[Phoenix-4 requirements](https://docs.tavus.io/sections/faces/phoenix-4-video-requirements)；[consent statement](https://docs.tavus.io/sections/troubleshooting/consent-statement)；[create replica API](https://docs.tavus.io/api-reference/phoenix-replica-model/create-replica.md)
- bitHuman：Essence 2 一次性 $5，几分钟就绪；Expression 2 一次性 $20，耗时更长。— [bitHuman pricing](https://www.bithuman.ai/pricing)
- Simli：通过 create-avatar 工具上传图片生成。— [Simli dev.to](https://dev.to/simli_ai/how-to-create-real-time-ai-video-avatar-in-7-minutes-2i29)

### Gaps
- Simli、Beyond Presence、LiveAvatar、Synthesia 的形象创建流程（照片还是视频、时长、授权要求）未能从文档中确认。

## 问题 6：多语言唇形同步（印尼语）

### Takeaway
没有任何厂商在本次查到的资料中**明确点名“印尼语”**。不过在我们的架构下（ElevenLabs 生成印尼语音频，avatar 只按音频驱动口型），唇形同步本质上与语言无关，风险较低，但仍需人工验证。

### Cited Findings
- 各家宣称的语言数（anam 对比页，2026-11-03）：anam 70+，Tavus 42+，HeyGen 100+，Synthesia 30+，LemonSlice 155+，LiveAvatar 175+，Akool 140+。这些数字主要指其全托管管线（STT/TTS）。— [anam compare](https://anam.ai/compare)
- Tavus 的训练视频可用任何语言录制，对话最多支持 30 种语言（与上面的 42+ 冲突）。— [Tavus replica training](https://docs.tavus.io/sections/replica/replica-training)

### Inferences
- 音频驱动模型（Simli、bey S2V、bitHuman、LiveAvatar LITE、anam passthrough）的口型只取决于音频的音素，理论上与语言无关（推断）。印尼语以拉丁字母书写、音素与英语差异不大，风险较低。

### Gaps
- 没有印尼语唇形同步的实测或用户反馈。

## 问题 7：从印尼和中国访问的区域、延迟及付款方式

### Takeaway

### Cited Findings

### Inferences

### Gaps
- 各厂商是否有 APAC 推理节点、是否接受印尼或中国的信用卡、是否支持 Stripe 以外的支付方式，均未查到。

### 人工任务
**通用测试方法**：在同一台浏览器、同一网络（最好从雅加达测一次）下，用同一位老师的同一张照片或视频建形象，用同一段 ElevenLabs 英语和印尼语音频驱动。参考 meet-cody 提出的六项测试：
1. 待机：静默 15 秒和 30 秒，观察是否僵硬或抖动。
2. 时钟：进行 30 轮以上对话，从录音中算出 p50 和 p95。
3. 冷启动：连续 20 次，记录首帧时间（TTFF）。
4. 打断：学生插话时，avatar 能否在 300ms 内闭嘴。
5. 弱网：1.5Mbps / 500ms 抖动 / 500kbps 三种条件。
6. 约 10 人盲测，与 anam 对比。

（方法来源：[meet-cody](https://meet-cody-website-xr0tt.kinsta.page/blog/real-time-ai-avatar-models-compared/)）

1. **Simli（Trinity-2）**：最便宜，也最接近直接替换 anam。
   - 注册后在 dashboard 获取 API key（入口见 https://docs.simli.com/ ）。
   - 用 https://docs.simli.com/simli-sdks 的 JS SDK 在 Next.js 中搭建：后端签发 token，前端把 ElevenLabs 输出重采样成 16kHz PCM 后推给 Simli。
   - 重点看：待机表现（口碑偏弱）、印尼语口型、照片建形象的相似度、Scale 档的 50 并发。
   - 价格以 https://www.simli.com/pricing 为准。
2. **Beyond Presence（Speech-to-Video）**：画质和带宽自适应口碑好，€0.0875/分钟。
   - 按 https://docs.bey.dev/integrations/speech-to-video.md 用 LiveKit 插件接入（需要搭 LiveKit Agents 服务端）。
   - 重点看：真人老师形象的创建流程和授权要求（文档未查清）、画质是否“像吉祥物”、从印尼访问的延迟。
   - 价格以 https://www.beyondpresence.ai/pricing 为准。
3. **Synthesia Interactive Avatars（avatar-only $0.10）**：在 anam 自测的 LiveKit 对照中与 anam 速度相当，首发送 500 分钟。
   - 按 https://docs.livekit.io/agents/models/avatar/plugins/synthesia 接入（仅支持 Python）。
   - 重点看：能否用真人老师建自定义形象、画质、并发上限，以及“full stack $0.20”何时上线。
   - 价格以 https://www.synthesia.io/api-pricing 为准。
- 备选：
  - **bitHuman**：适合做亚太自托管和成本试验，$0.02–0.04/分钟，见 https://www.bithuman.ai/pricing
  - **HeyGen LiveAvatar LITE**：降价后约 $0.085/分钟。建议财务重新核算当初否掉 HeyGen 的依据，见 https://docs.liveavatar.com/docs/faq/credits
- 对 anam 本身：建议直接和销售谈 Enterprise 价（定价页写“起价 $0.04”）和 APAC 区域，作为谈判筹码与上述报价对比。
