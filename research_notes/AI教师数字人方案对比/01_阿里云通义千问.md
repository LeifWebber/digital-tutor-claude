## 一、阿里云有哪些相关产品，现在的状态如何（产品清单）

### Takeaway
目前能用的有四条线。(1) 百炼/DashScope 的“音频驱动视频”模型，用于预渲染：wan2.2-s2v、wan2.7-i2v（driving_audio）、VideoRetalk。(2) 万相数字人（原“灵眸”，原“虚拟数字人”产品）：提供 SaaS 视频创作、2D/3D 实时对话数字人和形象定制。(3) 智能媒体服务 IMS 的“AI 实时互动”工作流，数字人节点只能接“阿里灵境”或第三方“相芯”。(4) 千问 Omni Realtime 和 Qwen-Audio/CosyVoice TTS，作为语音组件。EMO（emo-v1）和 LivePortrait 很可能已在 2026-10-10 下线，Animate Anyone gen2 也已下线，替代为 wan2.7-r2v。

### Cited Findings
- **wan2.2-s2v（万相-数字人）**：输入单张图片加音频，生成“动作自然的说话、唱歌或表演视频”。支持肖像、半身、全身图片，也支持卡通形象。调用流程是先用 wan2.2-s2v-detect 做合规检测，再异步生成 — [wan-s2v overview](https://help.aliyun.com/zh/model-studio/wan-s2v-overview/)；[wan-s2v api](https://help.aliyun.com/zh/model-studio/wan-s2v-api)
- 中国站文档写明 wan2.2-s2v 只适用于华北2（北京），必须使用北京地域的 API Key — [wan-s2v api](https://help.aliyun.com/zh/model-studio/wan-s2v-api)。国际站英文 API 页（更新于 2026-10-27）也写“applies only to the China (Beijing) region”，但其中的 Python 示例写的是 `region="ap-southeast-1"`，前后矛盾 — [Intl wan-s2v api](https://www.alibabacloud.com/help/en/model-studio/wan-s2v-api)
- **wan2.7-i2v / wan2.7-i2v-2026-04-25**：图生视频，功能列表包含“音频驱动”，支持 720P/1080P，时长 2–15 s，30 fps — [视频生成模型列表](https://help.aliyun.com/zh/model-studio/video-generate-edit-model)。国际站文档说明：在 `media` 里传入 `"type":"driving_audio"`，模型会把它“用作口型同步和动作节奏的驱动源”。音频格式 wav/mp3，长度 2–30 s，大小 ≤15 MB，超出 duration 的部分会被截断。北京和新加坡两个地域都可用。文档更新于 2026-10-27 — [Intl image-to-video general API](https://www.alibabacloud.com/help/model-studio/image-to-video-general-api-reference)
- 同一份视频模型列表还有以下模型：wan2.5-i2v-preview、wan2.6-i2v、wan2.6-i2v-flash（列表描述为“image-to-video with audio sync”）；happyhorse-1.1-i2v（可输出音频，未写明能否输入驱动音频）；wan3.0-video / wan3.0-video-prime（2–30 s，提到 reference audio，未写明支持口型同步）；wan2.2-animate-move / mix（用参考视频的动作驱动人物或做人物替换，720P，2–30 s）— [视频生成模型列表](https://help.aliyun.com/zh/model-studio/video-generate-edit-model)
- **VideoRetalk（声动人像，视频口型替换）**：输入一段人物视频加一段语音，输出口型与语音对齐的新视频。只能通过 API 调用，不能在百炼控制台在线体验。只有北京地域 — [videoretalk](https://help.aliyun.com/zh/model-studio/videoretalk)
- **EMO / LivePortrait**：搜索到的百炼下线列表显示，liveportrait、liveportrait-detect、emo-detect-v1（图像生成与编辑类）和 emo-v1（视频生成类）的下线时间是 2026-10-10 00:00；animate-anyone-gen2 的替代模型是 wan2.7-r2v — [模型下线页（搜索摘要）](https://help.aliyun.com/zh/model-studio/model-depreciation)。我直接抓取该页面时，只看到批次日期和公告链接，没有模型名。公告 118344 写的是“部分历史主线模型下线通知”，生效时间北京时间 2026-10-10 00:00，发布于 2026-06-08，正文同样没有列出模型名 — [公告 118344](https://www.aliyun.com/notice/118344)。另外，`help.aliyun.com/zh/model-studio/emo-api` 和 `/liveportrait-api` 现在都会跳回模型索引页，国际站的 liveportrait 页面返回 404 — [emo-api](https://help.aliyun.com/zh/model-studio/emo-api)；[Intl liveportrait](https://www.alibabacloud.com/help/en/model-studio/liveportrait)
- EMO 的历史价格（已下线，仅供参考）：1:1 画幅 0.08 元/秒，3:4 画幅 0.16 元/秒，免费 1,800 秒。英文页标价为 $0.011469 / $0.022937 每秒，更新于 2025-10-21 — [EMO quick start](https://help.aliyun.com/en/model-studio/emo-quick-start/)；[Intl EMO](https://www.alibabacloud.com/help/en/model-studio/emo-quick-start)
- **万相数字人（原虚拟数字人/灵眸）**：文档目录标注“虚拟数字人（文档停止维护）”，最后更新于 2025-08-11。产品现名为“通义万相数字人”，提供 2D 视频/图片形象定制、3D 官方模型、声音克隆、SaaS 视频创作、实时对话和直播 — [avatar product overview](https://help.aliyun.com/zh/avatar/avatar-application/product-overview/)；[什么是通义万相数字人](https://help.aliyun.com/zh/avatar/avatar-application/product-overview/what-is-lingmou)
- **IMS AI 实时互动**：实时工作流的数字人节点“目前支持阿里灵境数字人、相芯”。开通灵境需要提交工单，相芯需要去相芯官网开通并拿到 AvatarId。同一页面还写明“通义星尘”数字人形象已于 2025-08-31 下线 — [数字人集成](https://help.aliyun.com/zh/ims/user-guide/digital-human-integration)
- **千问 Omni Realtime**：当前在售的有 qwen3.8-omni-flash-realtime、qwen3.5-omni-plus-realtime、qwen3.5-omni-flash-realtime（含 2026-03-15 快照）、qwen3-omni-flash-realtime-2025-09-15，另有 qwen-audio-3.1-realtime-plus / flash（语音转语音）— [模型列表](https://help.aliyun.com/zh/model-studio/models)；[模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)
- 模型列表里还有一个 **happyoyster-1.0-acting（角色演绎）**，标注为“邀测”，归在“世界模型”类，页面没有说明它能否用作说话数字人 — [模型列表](https://help.aliyun.com/zh/model-studio/models)
- 另有一套“/me”路径下的计费文档（疑似云码智创/虚拟人另一套体系），列出 2D 实时互动按路包月基础版 2,000 元、高级版 3,000 元。无法确认它和万相数字人是同一产品 — [me billing description](https://help.aliyun.com/zh/me/product-overview/billing-description)

### Inferences
- 预渲染优先看 wan2.7-i2v（driving_audio，1080P，30 fps，支持新加坡）和 wan2.2-s2v（单张图，480P/720P，仅北京）。如果老师能提供一段真人视频，VideoRetalk 便宜一个数量级。
- 实时互动方面，阿里云官方目前只有“万相数字人 2D/3D 实时对话”这一个自营方案。IMS 工作流里的数字人要么走灵境工单，要么走第三方相芯。没有发现百炼直接提供“realtime avatar”模型。

## 二、预渲染（离线生成老师讲解视频）：能力、输入、速度、限制

### Takeaway
wan2.2-s2v 每段音频必须短于 20 秒，单账号同时只能跑 1 个任务，每段生成约 5–10 分钟，所以 45 秒的课程片段要切 3 段串行生成。wan2.7-i2v 每段最长 15 秒，生成约 1–5 分钟，支持 1080P。VideoRetalk 用真人视频底板替换口型，价格最低（0.08 元/秒），但同样只能 1 并发。万相数字人 SaaS 控制台可以直接上传音频生成视频，按积分计费，但官方没给出 API 视频创作的价格。

### Cited Findings
- wan2.2-s2v 输入图片：jpg/jpeg/png/bmp/webp 格式，宽高 400–7000 px，必须是公网 URL。输入音频：wav/mp3 格式，小于 15 MB，**小于 20 秒**，要求人声清晰响亮，并去除噪音和背景音乐。输出视频时长等于音频时长，更长的内容需要分段生成后拼接 — [wan-s2v api](https://help.aliyun.com/zh/model-studio/wan-s2v-api)
- wan2.2-s2v 输出 480P（约 640×480，4:3，默认）或 720P（约 1280×720，16:9），尽量保持输入图片的宽高比，示例输出为 16 fps — [wan-s2v api](https://help.aliyun.com/zh/model-studio/wan-s2v-api)
- wan2.2-s2v 生成时间约 5–10 分钟，建议每 15 秒轮询一次。主账号和 RAM 子账号共享限流，**同时处理中的任务数为 1**，查询 QPS 20。结果 URL 和任务数据保留 24 小时 — [wan-s2v api](https://help.aliyun.com/zh/model-studio/wan-s2v-api)；搜索摘要另称提交 RPS 为 5 — [WebSearch 摘要/wan-s2v overview](https://help.aliyun.com/zh/model-studio/wan-s2v-overview/)（官方表格的列对应关系不清楚，两个数字有冲突）
- 接口地址：`POST https://dashscope.aliyuncs.com/api/v1/services/aigc/image2video/video-synthesis`，请求头需带 `X-DashScope-Async: enable`；查询地址 `GET https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/tasks/{task_id}`；参数 `parameters.style="speech"` — [wan-s2v overview](https://help.aliyun.com/zh/model-studio/wan-s2v-overview/)
- 官方选型建议：需要全身或大半身视频时用 wan2.2-s2v，追求性价比时选 EMO（EMO 现已下线）— [WebSearch 摘要](https://help.aliyun.com/zh/model-studio/wan-s2v-overview/)；国际站数字人概览曾写“Wan 数字人替代 EMO”，并建议超过 20 秒、头部动作简单的播报类视频使用 LivePortrait（LivePortrait 现已下线）— [Intl video-generation](https://www.alibabacloud.com/help/en/model-studio/video-generation)
- wan2.7-i2v：时长为 2–15 秒的整数（默认 5 秒），720P/1080P（默认 1080P），按秒计费，图生视频一般需要 1–5 分钟。模型、endpoint 和 API Key 必须属于同一地域（新加坡或北京）— [Intl image-to-video general API](https://www.alibabacloud.com/help/model-studio/image-to-video-general-api-reference)
- VideoRetalk：输入要求是“画面清晰且正面镜头的人物视频”加上清晰的人声音频。提交 RPS 为 1，并发任务数 1，多余任务排队 — [videoretalk](https://help.aliyun.com/zh/model-studio/videoretalk)
- 万相数字人视频创作（控制台）：可以输入文本（调用 TTS），也可以上传或现场录制音频作为成片音轨。画幅可选 16:9 或 9:16，建项后不能修改。生成时长取决于文本长度。控制台地址 https://avatar.console.aliyun.com/lingmou/videoTemplates — [视频创作指南](https://help.aliyun.com/zh/avatar/avatar-application/user-guide/avatar-video-operation-guide)
- 万相数字人会员页写明 4K 输出“即将推出”，视频创作消耗 1 积分/秒 — [会员与积分](https://help.aliyun.com/zh/avatar/avatar-application/product-overview/avatar-membership-subscriptions-and-credits-packages)

### Inferences
- 以 wan2.2-s2v 在单账号 1 并发下串行生成为例：45 秒片段切成 3 段，每段 5–10 分钟，总共约 15–30 分钟。一节 10 分钟的课约 30 段，需要 2.5–5 小时。批量生产要么多开账号，要么申请提高并发。
- 分段拼接时，段与段交界处可能出现姿态或表情跳变，长视频的一致性要靠实测确认。
- wan2.7-i2v 有新加坡地域，如果后续面向印尼部署或有数据合规要求，可以优先考虑。

### Gaps
- wan2.2-s2v 和 VideoRetalk 的实测 RTF 没有官方数据（只有“5–10 分钟”这个区间）。VideoRetalk 的输入时长上限、输出分辨率和 fps 文档没写。
- wan2.6-i2v / wan2.6-i2v-flash / wan2.5-i2v-preview 是否接受外部驱动音频并做口型同步，没有拿到官方参数说明。列表里的“audio sync”可能只是指自动配音。
- 万相数字人视频创作的 API 调用方式、单条最长时长和分辨率都没查到。

## 三、实时互动（学生说话、老师低延迟回答）：方案、延迟、SDK、自带 LLM

### Takeaway
官方自营的实时数字人只有“万相数字人实时交互-2D/3D”。浏览器端只能用 **2D 云渲染**（有 Web SDK），端渲染只支持 iOS/Android。它分“全链路”（ASR+LLM+TTS+驱动一体）和“音频驱动”（只买口型驱动，自己提供语音）两种模式，后者理论上可以接我们自己的 LLM 和 ElevenLabs。另一条路是 IMS AI 实时互动工作流，它支持接入自研模型，但数字人节点依赖灵境（需工单）或相芯。所有渠道都没有找到官方的首帧或端到端延迟数据。

### Cited Findings
- 2D 实时对话有两种渲染方式。云渲染：模型推理、渲染和口型都在服务端完成，视频推流到客户端，适合对画质要求高的 IP 形象。端渲染：在设备上跑轻量模型，适合 UGC 和高并发场景。集成方式也有两种。全链路：ASR、LLM、TTS、驱动通过一个 SDK 集成。音频驱动：已经有实时语音对话的客户只集成驱动部分 — [2D 实时对话](https://help.aliyun.com/zh/avatar/avatar-application/user-guide/avatar-2dchat/)
- SDK 支持情况：**云渲染支持 Web SDK、iOS SDK、Android SDK；端渲染只支持 iOS SDK、Android SDK** — [2D 实时交互计费](https://help.aliyun.com/zh/avatar/avatar-application/product-overview/price-videochat-2d)
- 全链路产品里官方的 TTS 和 ASR“暂不收取额外费用”。使用大语言模型会产生对应 LLM 的费用 — [2D 实时交互计费](https://help.aliyun.com/zh/avatar/avatar-application/product-overview/price-videochat-2d)
- 免费试用：每个阿里云客户有 7 天试用，最多可创建 10 个 2D 项目。云渲染项目可以在控制台里直接对话；端渲染项目和 SDK 调用需要先购买。控制台地址 https://avatar.console.aliyun.com/lingmou/chat — [2D 实时对话](https://help.aliyun.com/zh/avatar/avatar-application/user-guide/avatar-2dchat/)
- SDK 参考文档区分“数字人对话-云渲染”和“数字人对话-纯端渲染”两套 — [SDK 参考](https://help.aliyun.com/zh/avatar/avatar-application/developer-reference/sdk-reference/)（搜索摘要）
- IMS AI 实时互动：基础功能包括数字人集成、打断智能体讲话、把用户信息透传给百炼或自研模型，还有 TTS 标准接口 — [conversational ai basic features](https://help.aliyun.com/zh/ims/user-guide/conversational-ai-basic-features/)。数字人节点（Avatar3D）位于 TTS 节点和 RTC 输出节点之间，使用“数字人通话/视频通话”模板。工作流控制台 https://ims.console.aliyun.com/ai/workflow/list — [数字人集成](https://help.aliyun.com/zh/ims/user-guide/digital-human-integration)
- 百炼多模态交互开发套件提供“三方 RTC 接入”：客户端通过 RTC 与服务端建立连接，服务端把视频帧发给多模交互 SDK。LiveAI 发送图片只支持 base64，单张小于 180K — [third party rtc invoke liveai](https://docs.bailian.console.aliyun.com/zh/model-studio/third-party-rtc-invoke-liveai)（搜索摘要）
- Qwen3.5-Omni 技术报告称采用 chunk 流式输入和流式 Talker，可做低延迟的端到端对话，但**没有公布具体延迟**。第三方文章称前代 Qwen3-Omni Flash（2025-12）延迟 234 ms（非官方）— [Qwen3.5-Omni report](https://arxiv.org/html/2604.15804v2)；[digitalapplied（第三方）](https://www.digitalapplied.com/blog/qwen-3-5-omni-omnimodal-256k-113-languages-guide)

### Inferences
- 要在浏览器里替换 anam.ai，最接近的方案是“2D 云渲染 + 音频驱动”（2,400 元/路/月）：我们自己负责 LLM 和 ElevenLabs TTS，把音频流推给阿里驱动口型。这需要确认 Web SDK 的音频驱动模式能否接收外部 PCM 流，以及它的传输协议（WebRTC 还是 RTMP/自有协议）。
- 全链路模式的 LLM 能否替换成我们的 OpenAI 兼容模型，文档只说“使用 LLM 会产生对应 LLM 费用”，没有说明能否接第三方。
- 包月按“路”（并发）计价，对课堂高峰并发不友好，需要按峰值并发来买。

### Gaps
- 2D/3D 实时数字人的首帧时间、端到端响应延迟、Web SDK 的传输协议（是否 WebRTC），都没找到官方数据。
- 3D 实时交互的价格页（“数字人实时交互-3D”）没有抓取到。
- 灵境数字人的价格和能力只能通过工单获取，没有公开资料。

## 四、语言支持（英语、印尼语、中文）和外部音频（ElevenLabs）驱动

### Takeaway
wan2.2-s2v、wan2.7-i2v（driving_audio）、VideoRetalk 和万相数字人视频创作都接受外部 mp3/wav，所以 ElevenLabs 生成的 MP3 可以直接拿来驱动口型。但没有任何官方文档说明英语或印尼语的口型效果，需要实测。TTS 方面，CosyVoice-v3-flash（系统音色和复刻音色都支持印尼语）和 qwen-audio-3.1-tts（复刻音色支持印尼语）可以作为 ElevenLabs 的替代；qwen3-tts-flash 不支持印尼语。

### Cited Findings
- wan2.2-s2v 的音频要求是 wav/mp3、小于 20 s、小于 15 MB，文档没有说明支持哪些语言，只要求人声清晰 — [wan-s2v api](https://help.aliyun.com/zh/model-studio/wan-s2v-api)
- wan2.7-i2v 的 driving_audio 支持 wav/mp3，2–30 s，不超过 15 MB — [Intl image-to-video general API](https://www.alibabacloud.com/help/model-studio/image-to-video-general-api-reference)
- 万相数字人视频创作可以上传本地音频作为成片音轨 — [视频创作指南](https://help.aliyun.com/zh/avatar/avatar-application/user-guide/avatar-video-operation-guide)
- TTS 语言矩阵（来自 TTS 模型列表）：qwen-audio-3.1-tts-flash/plus 支持中、英，复刻音色还支持印尼语，北京和新加坡都可用；cosyvoice-v3-flash 的系统音色和复刻音色都支持中、英、印尼语，北京和新加坡可用；cosyvoice-v3.5-plus/flash 只有复刻音色支持印尼语，仅北京；cosyvoice-v3-plus 的复刻音色不支持印尼语；cosyvoice-v2 和 qwen3-tts-flash(-realtime) 不支持印尼语 — [TTS 模型列表](https://help.aliyun.com/zh/model-studio/tts-model)

### Inferences
- 音频驱动类模型原理上与语言无关，但这些模型的训练数据以中文为主。英语，尤其印尼语的口型准确度（如 /p/ /b/ /m/ 等闭唇音）是主要风险点，必须用我们手上的 4 段测试音频实测。
- 如果实时链路选千问 Omni，印尼语的语音输出可能不支持，那就得改用“Omni/LLM 出文本，再接外部 TTS”。

### Gaps
- 没找到任何官方或第三方资料评测阿里数字人模型在英语、印尼语上的口型效果。
- 万相数字人 2D 实时对话的全链路 ASR/TTS 支持哪些语言，没有查到。

## 五、定制数字人（用老师的照片或短视频）：流程、素材、时间、费用

### Takeaway
百炼模型（s2v、wan2.7）不需要“定制”，每次调用传一张照片即可，只是要过 detect 合规检测。万相数字人的定制分四档：图片免训练版（100 积分）、图片训练版（约 0.5 小时，控制台 390 积分，API 39 元）、小样本视频版（需要 10 秒–2 分钟视频）、高精度视频版（需要 5 分钟视频，39,990 积分，约 3,400–4,000 元）。实时对话使用定制形象，需要同时支付形象训练费和实时交互订阅费。

### Cited Findings
- 图片训练版：jpg/jpeg/png 格式，400–7000 px，不超过 10 MB；要求单人站姿、动作简单、双肩完整、手里不拿东西；正脸，偏转小于 15°；不戴帽子、面部无遮挡、不能是动漫图；API 上传前需裁成 9:16。训练约 0.5 小时，完成后在控制台确认。控制台目录价 390 积分/个（预扣），API 后付费 39 元/个。训练好的形象可以用于视频创作和实时对话 — [2D 图片形象定制](https://help.aliyun.com/zh/avatar/avatar-application/user-guide/customized-digital-2d-image-avatar/)
- 积分价目：高精度视频版 39,990 积分/个，图片训练版 390 积分/个，图片免训练版 100 积分/个。声音克隆在限时活动期间对会员免费 — [会员与积分](https://help.aliyun.com/zh/avatar/avatar-application/product-overview/avatar-membership-subscriptions-and-credits-packages)
- 素材要求：高精度视频版需要一段 5 分钟视频；小样本视频版需要 10 秒–2 分钟视频；图片训练版适用于没有视频素材的情况。用定制的 2D 图片形象做对话，需要支付“形象训练费 + 数字人实时交互-2D 订阅费”两笔费用 — [搜索摘要：customized digital avatar classification / product activation faq](https://help.aliyun.com/zh/avatar/avatar-application/user-guide/customized-digital-avatar-classification)
- 万相数字人是公共云产品，不承接私有化部署 — [product activation faq（搜索摘要）](https://help.aliyun.com/zh/avatar/avatar-application/support/product-activation-faq)

- 声音复刻（qwen-voice-enrollment）：每次复刻 $0.01，新加坡地域每个账号有 1,000 个免费额度 — [Intl model pricing](https://www.alibabacloud.com/help/en/model-studio/model-pricing)

### Inferences
- 快速验证可以直接用老师照片调 wan2.2-s2v 或 wan2.7-i2v，零定制成本。要做实时数字人就得走万相数字人，先用图片训练版（39 元）验证，满意后再考虑高精度视频版。
- 积分换算：100 积分 = 10 元，8,000 积分 = 680 元，所以 1 积分约 0.085–0.1 元。高精度视频版 39,990 积分约 3,400–4,000 元，约合 $480–563（推算）。

### Gaps
- 小样本视频版的积分价格、各档的审核时长，以及是否需要真人授权书或授权视频，都没有查到（图片训练版页面完全没提授权）。
- 3D 形象定制的流程和价格未查。

## 七、质量口碑（自然度、牙齿/唇部伪影、长视频一致性）

### Takeaway
找到的质量证据基本都是阿里团队自报的：Wan-S2V 论文称在与 Hunyuan-Avatar、OmniHuman 的对比中表现更好。没有找到知乎、B 站或掘金上关于牙齿、唇形或长视频一致性的独立测评，必须自己用同样素材做 A/B 测试。

### Cited Findings
- Wan-S2V 由通义实验室 HumanAIGC 团队发表，论文称在影视级场景中的表现力和保真度显著优于 Hunyuan-Avatar 和 OmniHuman（作者自报）— [arXiv 2508.18621](https://arxiv.org/html/2508.18621v1)
- ComfyUI Wiki 列出了 FID 15.66、CSIM 0.677、SSIM 0.734 等指标，但没说明和哪些模型对比，也没有专门评估口型 — [ComfyUI Wiki](https://comfyui-wiki.com/zh/tutorial/advanced/video/wan2.2/wan2-2-s2v)
- 一个第三方论文摘要站称其口型同步精度为“±2 frames”（并非论文原文，可信度低）— [ai-search.io](https://ai-search.io/papers/wan-s2v-audio-driven-cinematic-video-generation)
- Wan2.2-S2V 已开源（2025-08 发布），可以通过 ComfyUI 本地运行 — [betanews](https://betanews.com/2025/08/28/alibaba-launches-new-open-source-tool-that-turns-photos-into-video/)；[ComfyUI Wiki 新闻](https://comfyui-wiki.com/en/news/2025-08-26-wan-s2v-audio-driven-video-generation)

### Inferences
- s2v 的示例输出是 16 fps、最高 720P，在课件旁的小窗里可能够用，但全屏会显得不够清晰。wan2.7-i2v 是 1080P、30 fps，画质更好，但每段只有 15 秒，更容易出现拼接不一致。
- 开源的 Wan2.2-S2V 可以作为自部署的备选，绕开 1 并发的限制，代价是需要 GPU。

### Gaps
- 中文社区没有可信的横向实测；万相数字人 2D 实时对话的画质也没有任何公开评测。

### 人工任务清单（推断 / 建议，需要人工执行）
1. **开通与 Key**：在百炼控制台开通服务，在北京地域创建 API Key（s2v 和 VideoRetalk 只能用北京 Key），再另建一个新加坡 Key 用于 wan2.7-i2v 对比。确认账号是否已实名。
2. **s2v 测试**：把老师照片和 4 段 MP3 上传到公网 URL（OSS）。先调用 wan2.2-s2v-detect，再分别跑 480P 和 720P。45 秒的音频要先切成 3 段，每段不超过 20 秒。记录：排队加生成耗时（秒/每秒视频）、英语和印尼语闭唇音的口型、牙齿和嘴唇伪影、分段拼接处是否跳变。确认免费额度扣减情况（控制台费用中心）。
3. **wan2.7-i2v（driving_audio）测试**：同一张照片，720P 和 1080P 各跑一次，每段不超过 15 秒。对比 s2v 的画质和口型。确认中国站人民币单价（百炼控制台模型详情页）。顺带验证 wan2.6-i2v-flash 是否接受外部音频驱动。
4. **VideoRetalk 测试**：请老师录一段 30–60 秒的正面讲课视频，用 4 段 MP3 替换口型。确认中文页写的 1,800 秒免费额度是否生效，并测量最大输入时长。
5. **万相数字人**：(a) 在控制台用老师照片做“图片训练版”（390 积分，约 0.5 小时），记录有没有授权或审核环节以及实际耗时；(b) 在视频创作里上传 MP3 生成视频，记录积分消耗和画质；(c) 用 7 天试用的 2D 云渲染项目，在浏览器里实测首帧时间和问答端到端延迟，并确认 Web SDK 是否基于 WebRTC、“音频驱动”模式能否接收外部 TTS（ElevenLabs）的音频流，以及全链路模式能否接自有 LLM。
6. **商务咨询**（电话 4008013260 或工单）：询问 3D 实时交互的价格、小样本视频版和高精度视频版的价格与授权书要求、s2v 并发能否提高、万相数字人“文档停止维护”是否意味着产品要下线、国际站是否提供万相数字人。
7. **IMS 路线（可选）**：在工作流控制台用“数字人通话”模板，通过工单申请开通灵境数字人参数，确认价格，以及 ElevenLabs 能否通过“TTS 标准接口”接入。
8. **语音组件**：用 cosyvoice-v3-flash 和 qwen-audio-3.1-tts（复刻老师声音，$0.01/次）生成同一段印尼语讲稿，与 ElevenLabs 对比；测试 qwen3.8-omni-flash-realtime 在英语和印尼语下的语音输出能力。
